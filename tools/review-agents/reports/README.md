# Staff review reports

Each completed run writes a Markdown report and matching JSON under `round-1/` or `round-2/`, named `head-coach`, `coordinator` or `position-coach`. Use the report header to identify the checkout, methods and test results. Each screenshot link is relative to its round. Source citations refer to the reviewed revision. The interview and quotes represent the simulated role.

Run each role separately with [the shared protocol](../PROTOCOL.md). Use [the comparison procedure](../compare.md) to recheck its first-round findings. A round-2 comparison records a disposition for every prior ID and lists new IDs. Keep the baseline and its evidence when applying an iteration.
